Intent: This document records a set of candidate first principles that have emerged through exploratory reasoning, system boundary mapping, and repeated confrontation with failure modes in deployed and conceptual AI systems. These principles are not presented as final truths or universal laws, but as a provisional scaffold for thinking, critique, and falsification. Their value lies in their ability to clarify constraints, surface assumptions, and guide measurement—not in asserting correctness.
